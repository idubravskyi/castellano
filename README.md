# castellano

Навчальний сайт з іспанської мови. Перший урок: **La acentuación** (A2–B1), пояснення українською.

## Структура
- `index.html` — готовий адаптивний сайт з теорією, практикою та тестом.
- Усі стилі й JavaScript вбудовані в один файл, зовнішні бібліотеки не потрібні.

## Публікація через GitHub Pages
1. Відкрийте репозиторій `castellano`.
2. Натисніть **Add file → Upload files**.
3. Завантажте `index.html` з цього архіву в корінь репозиторію.
4. Натисніть **Commit changes**.
5. Відкрийте **Settings → Pages**.
6. У **Build and deployment** виберіть **Deploy from a branch**.
7. Branch: `main`; Folder: `/ (root)`; натисніть **Save**.
8. Через 1–3 хвилини сайт буде доступний за адресою:
   `https://idubravskyi.github.io/castellano/`

Якщо GitHub Pages уже налаштований для `main` і `/ (root)`, достатньо завантажити `index.html`.

## Подальший розвиток
